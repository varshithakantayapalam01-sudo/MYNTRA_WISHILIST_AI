# Myntra Wishlist Decision Assistant

A mobile-first AI-powered shopping assistant that helps Myntra users convert wishlisted items into confident purchases.

## Features

- **Login Flow** — Phone + OTP authentication
- **Product Browsing** — Category-filtered product grid with wishlist hearts
- **Help Me Choose** — AI-powered side-by-side comparison of 2–4 wishlisted items
- **AI Review Summary** — Structured review intelligence across 6 categories
- **Product Confidence Card** — 0–100 confidence score with 10 purchase attributes

## Tech Stack

- Vanilla HTML5, CSS3, ES6 JavaScript
- 5 Specialized AI Agents (Orchestrator, Comparison, Review, Confidence, Recommendation)
- Mobile-first responsive design with Myntra branding

## Getting Started

Open `index.html` in any browser. No installation required.
